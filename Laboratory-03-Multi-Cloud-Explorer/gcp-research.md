# Google Cloud Platform Research

## Brief Overview

Google Cloud is a cloud computing platform provided by Google. It offers services for computing, storage, databases, networking, data analytics, artificial intelligence, machine learning, security, and application development.

Google Cloud enables organizations to deploy and manage applications and infrastructure using Google's global cloud infrastructure.

## Global Infrastructure

Google Cloud operates a global infrastructure organized into **Regions** and **Zones**.

Regions represent geographic locations, while Zones are isolated locations within Regions where cloud resources can be deployed.

This infrastructure allows organizations to deploy applications closer to users and design systems for availability, reliability, and resilience.

## Cloud Management Console

The **Google Cloud Console** is a web-based interface used for managing Google Cloud resources and services.

Users can create and configure virtual machines, storage, databases, networks, security settings, and other cloud resources through the console.

## Four Core Services

### 1. Compute Engine

**Google Compute Engine** provides configurable virtual machines that can be used to run applications and workloads in the cloud.

### 2. Cloud Storage

**Google Cloud Storage** provides scalable object storage for data such as files, backups, media, and application data.

### 3. Cloud SQL

**Cloud SQL** is a fully managed relational database service that supports database engines such as MySQL, PostgreSQL, and SQL Server.

### 4. Virtual Private Cloud (VPC)

**Google Cloud VPC** provides networking capabilities for connecting and securing cloud resources within Google Cloud.

## Three Advantages

1. **Data and Analytics Capabilities** – Google Cloud provides strong services for large-scale data processing and analytics.
2. **Global Infrastructure** – Google operates a worldwide cloud infrastructure that supports applications used by organizations around the world.
3. **AI and Machine Learning** – Google Cloud provides extensive artificial intelligence and machine learning services.

## Typical Enterprise Use Cases

Google Cloud is commonly used for:

- Web and application hosting
- Data analytics
- Machine learning and artificial intelligence
- Data storage and backup
- Database hosting
- Application development
- Global application deployment
- Big data processing
- Business intelligence
