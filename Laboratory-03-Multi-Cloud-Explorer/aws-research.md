# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers a wide range of cloud services, including computing, storage, databases, networking, security, analytics, and artificial intelligence.

AWS allows organizations to use computing resources over the internet without having to maintain all physical infrastructure themselves.

## Global Infrastructure

AWS operates a global cloud infrastructure organized into geographic **Regions** and **Availability Zones**.

A Region is a separate geographic area that contains multiple Availability Zones. Availability Zones are isolated locations within a Region that are designed to provide high availability, reliability, and fault tolerance.

AWS also uses edge locations to help deliver content and services closer to users around the world.

## Cloud Management Console

The **AWS Management Console** is a web-based interface used to create, configure, monitor, and manage AWS resources.

Through the console, users can access and manage services such as Amazon EC2, Amazon S3, Amazon RDS, networking resources, security services, and many other AWS services.

## Four Core Services

### 1. Amazon EC2

**Amazon Elastic Compute Cloud (EC2)** provides resizable virtual servers that organizations can use to run applications and workloads in the cloud.

### 2. Amazon S3

**Amazon Simple Storage Service (S3)** provides scalable object storage for files, documents, images, videos, backups, and other types of data.

### 3. Amazon RDS

**Amazon Relational Database Service (RDS)** is a managed relational database service that simplifies the process of setting up, operating, and scaling databases.

### 4. Amazon VPC

**Amazon Virtual Private Cloud (VPC)** allows organizations to create logically isolated networks and control networking resources within AWS.

## Three Advantages

1. **Scalability** – AWS resources can be increased or decreased based on workload requirements.
2. **Global Availability** – AWS provides cloud infrastructure across many geographic regions around the world.
3. **Wide Range of Services** – AWS provides services for computing, storage, databases, networking, security, analytics, artificial intelligence, and other enterprise requirements.

## Typical Enterprise Use Cases

AWS is commonly used by enterprises for:

- Website and web application hosting
- Data storage and backup
- Database hosting
- Application development and testing
- Data analytics
- Disaster recovery
- Enterprise application hosting
- Scalable business applications
