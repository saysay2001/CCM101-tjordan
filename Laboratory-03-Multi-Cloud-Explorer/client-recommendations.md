# CloudNova Technologies – Client Recommendations

## Client A – Startup Company

### Recommended Cloud Platform: Amazon Web Services (AWS)

**Amazon Web Services (AWS)** is recommended because the startup has a limited budget but expects rapid growth. AWS provides scalable cloud resources that allow the company to begin with the resources it needs and increase them as the mobile application gains more users. Its wide range of services also allows the startup to build and operate the application without investing heavily in physical infrastructure. AWS provides flexible options that are suitable for startups that need to control costs while preparing for future growth.

### Recommended Services

* **Amazon EC2** – Provides virtual servers for running application backends and other workloads.
* **Amazon S3** – Provides scalable storage for application files, images, videos, and other data.
* **Amazon RDS** – Provides a managed relational database for storing application data.
* **Amazon VPC** – Provides a secure virtual network for AWS resources.

---

## Client B – University

### Recommended Cloud Platform: Microsoft Azure

**Microsoft Azure** is recommended because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, making it easier for the university to migrate selected services to the cloud. The university can also use hybrid cloud capabilities to connect its existing on-premises infrastructure with Azure resources. This approach can reduce migration difficulties while allowing the university to gradually adopt cloud services.

### Recommended Services

* **Azure Virtual Machines** – Allows the university to run Windows Server workloads in the cloud.
* **Microsoft Entra ID** – Provides cloud-based identity and access management that integrates with Microsoft environments.
* **Azure SQL Database** – Provides a managed relational database service for university applications.
* **Azure Virtual Network** – Provides secure networking between Azure resources and existing infrastructure.

---

## Client C – AI Research Company

### Recommended Cloud Platform: Google Cloud Platform (GCP)

**Google Cloud Platform (GCP)** is recommended because the company focuses on Artificial Intelligence and Machine Learning applications that require high-performance computing. Google Cloud provides specialized infrastructure and services designed to support machine learning, data processing, and computationally intensive workloads. Its AI and machine learning ecosystem can help researchers develop, train, and deploy advanced models. Google Cloud is also well suited for organizations working with large datasets and cloud-native technologies.

### Recommended Services

* **Google Compute Engine** – Provides configurable virtual machines for high-performance computing workloads.
* **Google Kubernetes Engine (GKE)** – Provides managed Kubernetes for deploying and managing containerized AI and ML applications.
* **Vertex AI** – Provides tools and services for developing, training, and deploying machine learning models.
* **Google Cloud Storage** – Provides scalable storage for research datasets, models, and other files.

---

## Client D – Global E-Commerce Company

### Recommended Cloud Platform: Amazon Web Services (AWS)

**Amazon Web Services (AWS)** is recommended because the company serves customers around the world and requires highly available infrastructure. AWS provides a global infrastructure with multiple geographic Regions and Availability Zones that can support highly available applications. The company can also use automatic scaling services to increase or decrease computing resources according to customer demand. This makes AWS suitable for an e-commerce platform that may experience large changes in traffic during promotions, holidays, and other peak periods.

### Recommended Services

* **Amazon EC2** – Provides scalable computing resources for running the e-commerce application.
* **Elastic Load Balancing (ELB)** – Distributes incoming traffic across multiple application resources.
* **Amazon EC2 Auto Scaling** – Automatically adjusts the number of computing resources based on demand.
* **Amazon S3** – Provides scalable storage for product images, documents, backups, and other data.
* **Amazon CloudFront** – Helps deliver website content to users with lower latency through a global content delivery network.
