# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides cloud services for computing, storage, databases, networking, analytics, security, artificial intelligence, application development, and other business requirements.

Azure allows organizations to build, deploy, and manage applications and services using Microsoft's global cloud infrastructure.

## Global Infrastructure

Azure operates a global infrastructure consisting of geographic **Regions** and datacenters.

Azure Regions contain datacenters that provide cloud services to customers in different geographic locations. Azure also provides availability and redundancy features that help organizations design applications for reliability, resilience, and business continuity.

## Cloud Management Console

The **Azure Portal** is a web-based management interface used to create, configure, monitor, and manage Azure resources.

Administrators can use the portal to manage virtual machines, databases, storage, networking, security, application services, and other cloud resources.

## Four Core Services

### 1. Azure Virtual Machines

**Azure Virtual Machines** provide scalable virtual computing resources that allow organizations to run applications and operating systems in the cloud.

### 2. Azure Blob Storage

**Azure Blob Storage** is an object storage service designed for storing large amounts of unstructured data such as documents, images, videos, backups, and application data.

### 3. Azure SQL Database

**Azure SQL Database** is a managed relational database service based on Microsoft SQL Server technologies.

It allows organizations to use a database without having to manage much of the underlying database infrastructure.

### 4. Azure Virtual Network

**Azure Virtual Network** provides private networking capabilities that allow Azure resources to communicate securely with each other, the internet, and on-premises networks.

## Three Advantages

1. **Microsoft Ecosystem Integration** – Azure integrates closely with Microsoft technologies and enterprise products.
2. **Scalability** – Organizations can scale cloud resources according to their workload requirements.
3. **Enterprise Capabilities** – Azure provides extensive tools for security, identity, networking, databases, analytics, and application development.

## Typical Enterprise Use Cases

Azure is commonly used for:

- Enterprise application hosting
- Microsoft-based application workloads
- Database hosting
- Virtual machines
- Backup and disaster recovery
- Data analytics
- Application development and testing
- Hybrid cloud environments
- Business applications
