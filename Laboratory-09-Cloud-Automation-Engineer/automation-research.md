# Research: The Language of Automation

## 1. Bash Script

A Bash script is a file containing a series of Linux commands that run automatically in sequence to perform specific tasks. The `#!/bin/bash` line, called a shebang, tells the system to use the Bash shell to execute the commands in the file.

## 2. Variables

Variables are used to store information, such as folder paths, filenames, or passwords, so programmers do not have to type the same values repeatedly. For example, using `$BACKUP_DIR` makes a script easier to read and update because changing the folder path in one place can update its use throughout the script.

## 3. Cron Job

A cron job is a Linux feature that allows commands or scripts to run automatically at scheduled times or intervals. It is essential in cloud operations because it helps automate regular tasks, such as backing up files, cleaning temporary data, and running maintenance scripts, without requiring someone to execute them manually.
