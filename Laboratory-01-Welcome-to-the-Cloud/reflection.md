# Reflection

Completing this laboratory activity gave me my first hands-on experience working in a Linux environment through KillerCoda. At first, I found some tasks challenging because I was unfamiliar with Linux commands and how the terminal works. I encountered a few problems, such as understanding that Linux is case-sensitive when creating folders and learning how to save files using the Nano text editor. Although these issues slowed me down, they helped me understand how Linux works and taught me the importance of paying attention to details.

I also learned how to gather important system information, organize files and folders, and create documentation using Markdown. Creating my GitHub repository and organizing it as a Cloud Computing Portfolio helped me understand the importance of keeping technical work organized and properly documented. While setting up the repository, I experienced a few difficulties with GitHub, but solving them improved my confidence in using the platform.

Overall, this laboratory activity strengthened my basic Linux skills and introduced me to tools that are commonly used in cloud computing. I now feel more comfortable using the Linux terminal, working with GitHub, and documenting my work. I believe the knowledge and experience I gained from this activity will help me as I complete the remaining laboratory exercises throughout the semester.
