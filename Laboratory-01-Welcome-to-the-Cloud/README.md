# Laboratory 1 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to the Linux operating system and basic cloud computing concepts using the KillerCoda Ubuntu playground. I learned how to navigate a Linux environment, create and manage user accounts, gather system information, organize files and directories, and begin building a Cloud Computing Portfolio on GitHub.

---

## Objectives

The objectives of this laboratory activity are:

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.

---

## Activities Performed

During this laboratory activity, I completed the following tasks:

1. Launched an Ubuntu Linux environment in KillerCoda.
2. Created a new Linux user account with sudo privileges.
3. Collected system information, including the Linux distribution, kernel version, CPU information, memory, and disk space.
4. Created and organized folders and Markdown files.
5. Created a public GitHub repository for my Cloud Computing Portfolio.
6. Uploaded documentation and organized files in the repository.

---

## Linux Commands Used

| Command | Purpose |
|---------|---------|
| `whoami` | Display the current user |
| `pwd` | Show the current working directory |
| `hostname` | Display the system hostname |
| `adduser` | Create a new Linux user |
| `usermod` | Add a user to the sudo group |
| `su -` | Switch to another user |
| `cat` | Display the contents of a file |
| `uname -r` | Display the Linux kernel version |
| `lscpu` | Show CPU information |
| `free -h` | Display memory usage |
| `df -h` | Show disk space usage |
| `mkdir` | Create directories |
| `cd` | Change directories |
| `ls` | List files and folders |
| `nano` | Create and edit text files |
