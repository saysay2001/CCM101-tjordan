# Mission Reflection

This laboratory helped me understand cloud computing in a more practical way. For me, the **compute resource** is the most important component because it performs tasks and runs applications. Without CPU and memory, the other resources would not be able to perform their functions. I also learned how **Linux supports cloud computing** by providing a stable environment for managing servers, applications, storage, networking, and system resources. Using commands such as `lscpu`, `free -h`, `lsblk`, `df -h`, and `hostname -I` helped me understand what is happening inside a cloud-based Linux environment.

I also realized the importance of **technical documentation before deploying infrastructure**. Documentation provides a clear plan of what resources are needed and how they should work together. It can prevent mistakes and make it easier for others to understand and maintain the system. During this laboratory, I learned new skills in Linux system inspection, virtualization, cloud service comparison, and basic cloud architecture design. Creating an infrastructure for **Aveiro Digital Solutions** helped me understand how a user, Internet connection, network, compute resource, and storage can work together as one system.

My **GitHub portfolio** also improved because it now contains organized technical documentation that shows more than just finished projects. It shows my ability to research, document, analyze, and apply technical concepts. Overall, this activity helped me move from simply learning cloud concepts to actually applying them. It gave me a better understanding of how cloud infrastructure works and gave me skills that I can use in future IT projects and real-world environments.
