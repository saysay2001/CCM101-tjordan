# Research: Security Best Practices

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users only the permissions they need to perform their assigned tasks. It is important for cloud user accounts because it prevents unauthorized access to sensitive data and reduces the possible damage if an account is compromised.

## 2. Attack Surface

The attack surface of a virtual machine refers to all the points where an attacker could try to access or exploit the system. These include open ports, running services, applications, and network connections. Reducing unnecessary services and closing unused ports can help make the virtual machine more secure.

## 3. Default Deny Policy

A Default Deny Policy means blocking all network traffic or access unless it is explicitly allowed by a security rule. It is safer than blocking specific hackers individually because new or unknown attackers may use different IP addresses or methods. By allowing only necessary traffic, the system reduces unauthorized access and provides stronger protection.
